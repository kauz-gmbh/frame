The Converter for HEIC Files

The File on This Site

The library is one file, /js/vendor/heic-to.js. It is the file dist/csp/heic-to.js of the heic-to package, version 1.6.7, as published. The only change is a comment of three lines at its top, which names the library, its license, and this page.

The Source

The file is built from these sources:

  • heic-to 1.6.7: github.com/hoppergee/heic-to, tag v1.6.7. The same is in the package on npm.
  • libheif 1.23.7: github.com/strukturag/libheif, release v1.23.7.
  • libde265 1.0.16: github.com/strukturag/libde265, release v1.0.16.

To build the file, libheif and libde265 are compiled to JavaScript with the script build-emscripten.sh of libheif, with the settings USE_UNSAFE_EVAL=0 and LIBDE265_VERSION=1.0.16. The result is in the source of heic-to as src/lib/libheif-without-unsafe-eval.js. The script esbuild.mjs of heic-to then puts it into one file together with the code of heic-to.

Using a Changed Version

You may change the library and use your version with Frame. The library stays a file of its own, and the page loads it only when it meets the first HEIC file that the browser cannot read. A file that takes its place must be a JavaScript module that exports a function heicTo({ blob, type, quality }), which gives back a promise of the converted image as a Blob.

Nothing in the terms of Frame keeps you from changing the library, or from taking Frame apart to find an error in your change.
